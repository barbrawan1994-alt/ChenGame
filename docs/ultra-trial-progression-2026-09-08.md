# 逐位光之契约试炼

基于 PR #26 的战斗重构，替换原先通关一个时代就获得整批角色的解锁方式。每场挑战指定一位角色；首次胜利仅授予这一位，角色的现有形态随契约开放。五位初始角色保留，也能参加试炼积累首通成绩。

## 挑战规则

- 93 位角色各有独立试炼记录，时代只用于筛选。重复首胜回调、退出后的旧回调、未清空敌方队伍均不能发奖。
- 每场挑战时代怪兽与该角色投影；新生代为双打，其余为两名敌人的连续单打。
- 只使用队伍中前 3 名存活伙伴，至少 2 名，出战者均需满足最低等级。敌方按整支队伍最高等级加成，不能靠把高等级角色放在后排降低难度。
- 精英：4 徽章、最低 Lv.30 起、敌方等级 +2。大师：6 徽章、3 位不同角色首通、最低 Lv.50、等级 +3。传奇：8 徽章、12 位首通、最低 Lv.70、等级 +5。敌方等级上限 100，时代可能提高最低等级。
- 奥特之王、诺亚、雷杰多、赛迦、令迦、黑暗扎基等还有指定前置；完整依赖图通过可达性检查，无循环锁死。
- 投影使用对应角色必杀、光能或格斗招式，以及定位对应的防御、削弱、蓄势或医疗动作。投影按全场回合的 4 回合周期行动，第 3 回合安排必杀；怪兽第 4 回合重击。医疗必杀限 3 次。意图提前显示，控制、速度、守住、PP 与破绽等通用规则有效。
- 禁止道具，无经验、金币与忍术熟练度收益。胜负或主动结束均恢复进入前的完整队伍。

## 旧档与视觉

旧时代通关已经授予的角色保留，迁移为明确的角色 ID 列表；旧通关不能代替新的逐位试炼成绩。当前契约与宿主保留。新状态为 version 2，分别记录 `unlockedHeroIds` 与 `trialWins`。

光之必杀的数值结算仍按原规则结束变身；Canvas 演出保留施法角色肖像，直到光线或医疗反馈结束，避免必杀尚在飞行时画面已经回到普通精灵。演出结束、取消或退出时恢复原立绘可见性。

## 验证

- 93 个解锁路径、每次奖励数量、重复通关、非法角色、旧档归一化与迁移检查。
- 各角色敌方队伍、医疗次数、动作周期、等级与徽章门槛；全部前置逐步可达。
- 拒绝快速重复开启，退出后旧胜利不能发奖，结算仅接受当前试炼运行 ID。
- 16,005 个角色/形态/装备/天气案例、19 项战斗专项、131 项回归通过。
- PC 浏览器检查：逐位角色列表与唯一奖励、传奇门槛、获胜与退出恢复、单打及新生代双打、键盘目标选择、撤回指令、简化特效；光线和施法肖像通过 Canvas 像素检查。

`node scripts/ultra-trial-balance.cjs` 执行 72 场真实单打，使用妙蛙花、喷火龙、水箭龟，无装备、果实或门派。直接输出策略只选择评分最高的伤害技能；准备策略加入忍术、呼吸法和迪迦变身，由同一评分器选招。
