# 怪兽图鉴、精英遭遇与试炼路线

## 本次内容

- 248 个独立怪兽档案：昭和 121、平成 73、新生代 26、令和 28。机械怪兽、宇宙人和独立合成兽纳入名册，同一怪兽的换色、强化形态及角色投影不重复计数。
- 每档案有作品、属性、危险档位、招牌攻击、出没环境和战术提示。图片保存在本地 WebP 中，出处见 `public/assets/kaiju/sources.json`。属性、环境、招式数值是本游戏的改编规则。
- 图鉴支持名称/作品/招式搜索、时代/环境/危险等级筛选以及未发现/已遭遇/已讨伐状态。进度保存在 `ultraState.kaiju`，保留原有角色解锁及契约。
- 93 位奥特曼各有三条路线，共 279 个不同怪兽阵容。每场两只不同战术的怪兽加角色投影。新生代及交错战线使用双打。三路线共用该角色的首通记录，获胜仍只解锁一位。

## 遭遇与奖励

普通野外单打、双打可以变为怪兽精英战，剧情、道馆、指定神兽、生态守护者及活动池不会被替换。最低两枚徽章、抽取等级及最高存活伙伴等级达到 18；更高档位另设门槛。

| 档位 | 门槛 | 基础金币 | 击倒经验 | 额外胜利掉落 |
| --- | --- | --- | --- | --- |
| 精英 | Lv.18 / 2 徽章 | 1.8 倍 | 1.5 倍 | 橙橙果 2 |
| 强敌 | Lv.35 / 4 徽章 | 2.4 倍 | 1.9 倍 | 文柚果 3；25% 增强剂 |
| 灾厄 | Lv.55 / 6 徽章 | 3.2 倍 | 2.4 倍 | 木子果 5；45% 增强剂；18% 暗之石 |

怪兽等级比本次野外抽取等级高 2，上限 100。金币倍率在现有金币加成体系之前作用；双打取两只的平均金币倍率，经验逐只计算，额外掉落按最高档位并多一个树果。试炼不给野外奖励。必须击败全部对手才发金币和战利品，逃跑、战败仅保留已击倒目标的经验和图鉴记录。

随机池优先本地环境，叠加天气、夜晚及未发现权重；16% 的怪兽遭遇进入跨环境裂隙池。最近十种暂不重复，战后至少间隔一次普通遭遇。基础概率 18%，三次未遇到后递增，最高 38%；十次符合条件的普通遭遇后，下一次保底怪兽。存档保留近期记录和保底计数。

## 战斗规则

12 类战术使用现有招式、PP、状态、能力变化和行动意图系统，不引入绕过控制、命中、护盾或属性克制的伤害。再生只在半血以下的指定轮次发生，最多三次；歼灭炮后需要休整。双打错开循环，追猎型优先残血，炮击型轮换目标。

底层仍使用精灵工厂创建战斗实例，但显式设置怪兽属性、种族数值与招式，清除果实、装备、忍术及咒术来源。怪兽禁止捕捉，图鉴使用独立编号，不触发底层模板的传说精灵击杀成就。

## 验证记录

- `npm run check:regressions`：131 项通过。
- `npm run check:battle`：19 项通过。
- `npm run check:ultra`：93 角色、165 形态、16,005 个用例通过。
- `npm run check:kaiju`：248 种、4,960 次真实招式执行（全部招式与五种天气）、279 阵容、18,000 次随机遭遇通过；所有种类均可达，非裂隙遭遇约 80.7% 来自本地环境。
- `node scripts/kaiju-balance.cjs`：248 场普通对照、248 场怪兽单打、31 场怪兽双打，无 60 回合卡死。Lv.65 三只御三家最终形态、无装备果实门派、选择评分最高普通招式的样本中，平均回合数分别为 4.02、7.41、5.90。样本全部获胜，代表成型三人队的可承受性，不代表所有玩家构筑胜率。
- `node scripts/ultra-trial-balance.cjs`：72 场真实单打，无超时；佐菲准备流胜 5/12、普通攻击胜 1/12；赛罗两组均胜 4/12；诺亚两组均 0/12。传奇仍是需进一步培养与编队的挑战，不能用此样本声称所有构筑平衡。
- 248 张图片均解码成功、384×384、内容非空、哈希不同；总计约 4.81 MB，平均 19.4 KB，图鉴按需加载。
- 浏览器实测通过：图鉴筛选与图片、三条试炼路线、单角色首通、自然野外遭遇、捕捉拦截、胜利掉落与读档保留；1024/1280/1440 三种 PC 视口及双打四个站位、目标选择、撤销、精简特效、奥特曼必杀和光线画布像素均验证通过，无页面异常。
- 构建通过。首屏入口 166 KiB，怪兽图片不作为进入游戏的前置下载。

## 实测修复

- 不再将投影的空怪兽编号计入图鉴，并覆盖旧档空值归一化。
- 怪兽不能消耗大师球或被保存为底层精灵模板。
- 怪兽击杀不会错误推进模板物种的传说精灵击杀成就。
- 试炼路线共享角色奖励和原队伍快照，不能通过切换路线重复增加角色首通数。

## 边界

本次不把“知名怪兽”当作无边界的完整版权名录，明确发布上述 248 种。长期成长、全部玩家装备/果实/技能的笛卡尔积，以及所有剧情分支并未因此穷尽。后续可根据真实档位耗时、资源消耗和失败分布继续调整。
